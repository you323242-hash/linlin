# 主体、备案与渠道办理准备

## 当前安排

我拟在山东省办理经营主体登记，初期以免费游戏组队服务作为准备公开的业务范围，并按实际情况准备单位非经营性ICP备案。网站使用腾讯云中国大陆服务器。

目前仍在校学习，近期还有考试任务，尚未完成主体登记、备案和渠道申请。计划2026年10月底开始推进以下准备；这是拟办理的顺序，不是已经获批的事项清单，也不承诺审批时长或月底即可正式运营。

## 1. 先确定实际主体和公开业务范围

需要先结合实际经营场所、责任承担和后续业务计划，确定登记地点、主体形式及经营范围，并向拟登记地的市场监管窗口核实材料和办理方式。我目前没有把具体主体形式和登记场所写成已经确定的结果。

同时整理真实功能清单：免费组队、名片、招募、用户互动、账号管理，以及现有模拟付费页面。明确哪些功能拟公开、哪些只保留在受限测试中，避免申报描述与真实服务不一致。

预期形成：主体登记方案、实际业务说明和拟公开功能清单。

## 2. 向接入商核实备案方案并准备材料

结合实际主体和域名安排，通过腾讯云备案渠道核实单位非经营性ICP备案是否适合拟公开的免费组队业务，以及主体、负责人、网站和域名等材料要求。所需材料以届时官方及接入商要求为准，由本人准备和提交。

玩家名片、公开招募和小队沟通等功能应如实说明，不能仅以“免费”推断所有管理要求均已满足，也不通过隐藏实际互动功能改变业务描述。

预期形成：经核实的材料清单、真实业务介绍、提交记录及实际审核结果。当前这些办理结果尚未取得。

## 3. 核实与实际功能相关的管理及许可事项

以下问题需要结合业务与属地要求进一步确认：

| 事项 | 拟核实的内容 |
| --- | --- |
| 公开信息和用户互动 | 名片、招募、文字及图片等功能对应的内容管理、身份核实和其他适用要求 |
| 公安联网备案等事项 | 是否适用、适用时的流程和时限，向相应官方渠道核实 |
| 后续收费业务 | 陪玩订单、平台撮合与结算的实际范围是否涉及额外许可、渠道准入或其他要求 |
| 用户信息处理 | 收集目的、公开范围、保存与删除规则、核身和用户权利执行方式 |

这些是待确认事项，不代表每项一定适用，也不表示取得ICP备案即可覆盖全部业务条件。核实后再调整公开范围和办理清单。

## 4. 落实正式账号和外部渠道条件

站内账号密码、会话与游客身份已有实际实现。拟正式使用的邮件、短信、QQ或微信登录，应分别核实平台开发者及应用准入、主体或域名条件、隐私与使用要求，再准备申请和联调。

当前不以模拟验证码或自填账号资料代替正式身份核实。第三方登录能够提供什么身份信息、是否满足相应业务要求，也需要具体确认。

预期形成：已获准渠道、相应配置和联调验收结果，以及清楚可用的账号找回与管理流程。当前未完成正式外部渠道接入。

## 5. 先完成免费公测的运营准备

在确定的业务范围内，落实用户协议与隐私政策、问题接收与举报处置、必要的内容管理、账号和隐私执行责任人、备份恢复及异常值守安排。

按已有方案完成真实跨设备试用，复核浏览器可信访问、权限和数据保存、问题反馈及恢复能力。结合实际手续和验收情况决定是否具备公开测试条件，并明确暂停服务、处理故障和通知用户的办法。

预期形成：可执行的运营规则、责任与值守安排、实际验收记录及明确的公开范围。

## 6. 条件成熟后再准备真实交易

如果后续开展收费服务，再结合已核实的业务范围申请合适的商户和支付渠道，明确退款、服务者收益结算与争议处理责任，并完成正式渠道安全、回调验签、对账和异常恢复验收。

现有模拟流程为这一步提供业务验证基础，当前不据此开放真实收款。实际付款、结算或正式运营的启用，需要另行确认并有真实准入和验收依据。
