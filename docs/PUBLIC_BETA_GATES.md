# 公测与运营门禁

技术能力、外部审批和运营责任分别验收，不能相互替代。

1. 核心免费组队流程、越权检查、持久化、故障提示通过与候选对应的验证。
2. 公开范围、经营主体、域名备案及可能适用的业务资质以真实情况向接入商或主管部门确认；不能靠隐藏功能规避要求。
3. 正式账号渠道、适用身份要求、完整隐私告知和留存/注销执行应有实际证据。普通账号、QQ或手机号验证不自动等于满足所有实名要求。
4. 举报、内容处置、投诉、值守与反馈渠道明确，并进行真人跨设备试用。自动化检查不代替这些工作。
5. 可信 HTTPS 访问、备份恢复、独立灾备接收、监控告警与回退实际可用。
6. 付费服务仅在准入机构明确支持实际业务、结算和退款方案获准并验证后另行开放；禁止自行归集、代管或分账。

A：全部必要条件满足，才评估商业运营。B：核心技术与相应公开合规条件满足，可有限免费公测。C：关键条件仍缺，继续受限非收费内测。日期目标不降低门禁。
