# 三角洲玩家组队与服务平台

面向《三角洲行动》玩家的个人产品实践：以免费组队为基础，探索与陪玩服务衔接的业务流程。

本仓库整理自已部署的 R183 代码基线，新增 GitHub 源码阅读入口。前端、后端、数据库持久化和账号系统可在本地运行；**所有收付款、短信、外部认证及 AI 服务均未接入真实渠道，production 环境保持关闭。** 当前是受限测试项目，不是已正式营业的平台。

## 可以体验什么

- **免费组队**：端游/手游分区、游戏名片、招募筛选、申请与确认入队、小队沟通、组队记录。
- **账号与游客体验**：邮箱账号、独立游客身份、会话保持、退出撤权和访问权限保护。
- **模拟服务业务**：订单创建、模拟付款、服务者资料、匹配/接单、计时、评价及售后流程。不同流程的实际验证范围见[项目状态](docs/PROJECT_STATUS.md)，不能把模拟功能等同于真实商业服务。
- **项目介绍信**：无需登录展示，可关闭；同标签页刷新、跨页不重复，页脚可重新打开。
- **维护工具**：数据锁、备份/恢复、状态检查、限流与审计。仓库只提供代码和示例配置，不携带线上数据或凭据。

## 本地运行

需要 **Node.js 24 或更高版本**（使用内置 `node:sqlite`）。

```bash
git clone https://github.com/you323242-hash/linlin.git
cd linlin
npm ci
npm start
```

打开 **http://127.0.0.1:4174/teams.html**。普通启动不需要外部账号或环境密钥；首次启动会在被 Git 忽略的 `.local/` 创建本地数据库和认证密钥。可以在登录框选择游客体验，也可注册合成测试账号。

如需本地预置服务者等测试角色，可执行 `npm run seed:local`。该命令会输出**公开的合成测试账号资料**，不得用于部署；不要在这些账号中录入真实个人信息。

```bash
npm run check       # JavaScript 语法
npm test            # 独立测试库及页面冒烟
npm run dev:check   # 本地依赖/数据/服务状态
```

自定义配置参考 [config/local.env.example](config/local.env.example) 和[运行说明](docs/DEVELOPMENT.md)。`config/staging.env.example` 仅是受限测试环境模板，不能复制后直接开放服务。不要通过移除环境门禁接入真实交易。

## 目录

| 路径 | 用途 |
| --- | --- |
| `dist/` | **直接维护的前端源码**、页面、样式及素材；不是可重新构建后覆盖的产物 |
| `server/` | Node.js HTTP/API、账号、组队、订单及权限逻辑 |
| `db/` | 数据结构参考；实际初始化/升级由现有代码管理 |
| `tests/` | 模块、HTTP、权限、持久化、恢复及界面行为测试 |
| `scripts/` | 启动、测试、种子数据、备份、交付及诊断工具 |
| `config/`、`deploy/` | 不含凭据的环境与部署模板 |
| `docs/` | 公开架构、运行、安全边界及项目状态说明 |

原先的框架脚手架已退役。本仓库不包含旧 `archive/`、数据库、密钥、上传附件、运行日志、原始验收材料或本机 Git 历史。不要执行旧前端构建覆盖 `dist/`。

## 技术与本人参与

主要使用 HTML、CSS、JavaScript/ES Modules、Node.js、SQLite、Better Auth；部署方案使用 Linux 服务管理和 Caddy。

本人负责产品方向、需求与规则取舍、任务优先级、交互反馈及验收，在 Codex、Claude 等 AI 工具辅助下推进实现、测试和问题排查。AI 辅助不替代对业务事实、安全边界和验证结果的判断。本项目尚未完成充分的真实用户及市场验证。

## 公开范围与限制

- 当前不提供正式运营承诺；经营主体、备案、适用资质、正式认证/支付渠道和运营制度仍需完成相应准备与核实。
- 原云测试站点曾存在私有 CA 不受普通浏览器信任的问题；本地运行不依赖该站点或该证书。
- 自动化测试通过不等于真人跨设备验收、站外灾备验证或商业放行。
- 测试中的账号、密码和 `tests/tls-fixture.mjs` 证书/密钥均是公开合成夹具，**不能用于真实环境**。
- 仓库未附开源授权许可证；公开展示不代表授予额外使用许可。第三方依赖遵循各自许可证；素材说明见 [dist/assets/original/README.md](dist/assets/original/README.md)。
